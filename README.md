# Tcl/Tk for EDA & DFT

This repository contains training materials and exercises for Tcl/Tk, specifically tailored for Electronic Design Automation (EDA) and Design for Testability (DFT) workflows.

The course is available in two languages:

- [English (EN)](./en/)
- [Tiếng Việt (VI)](./vi/)

Please navigate to your preferred language directory to begin.
