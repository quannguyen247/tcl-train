# Exercism Tcl Track Practices

All practice exercises in this directory are sourced from the official [Exercism Tcl Track](https://exercism.org/tracks/tcl) under their open-source license.

## Structure
Each exercise directory contains:
- `<exercise_name>.tcl`: Contains problem instructions formatted as comments at the top, followed by the solution code stub.
- `<exercise_name>.test.tcl`: Standard `tcltest` suite.

## Running Tests
To run all 140 exercise tests automatically:
```bash
python run_all_tests.py
```
