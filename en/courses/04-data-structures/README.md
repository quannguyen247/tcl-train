# Module 04: Data Structures

This module introduces `list`, `array`, and `dict` in Tcl.

---

## 📖 Core Theory

### 1. `list`
`list` is ideal for ordered collections such as clock domains or pin names.

### 2. `array`
`array` is Tcl's associative key-value structure, useful for counting cell types or storing lightweight attributes.

### 3. `dict`
`dict` is better suited for structured data and nested mappings, especially when modeling timing or configuration data.
