## Opening and Closing Files

### Explanation
To interact with a file, you must first open it using the `open` command, which returns a channel identifier. You use this identifier for subsequent operations and must `close` it when done to release resources.

### Syntax
```tcl
set channelId [open filename mode]
close $channelId
```
Modes include `r` (read), `w` (write, truncates), `a` (append), `r+` (read/write), `w+` (read/write, truncates), `a+` (read/write, append).

### Example
```tcl
set fileId [open "report.txt" "w"]
puts $fileId "Generated by EDA Tool"
close $fileId
```

### Output
```
(A file named report.txt is created with the specified content)
```

## Reading and Writing

### Explanation
You can read files line-by-line using `gets`, or entirely using `read`. Use `puts` to write data.

### Syntax
```tcl
gets channelId varName
read channelId ?numBytes?
puts ?-nonewline? channelId string
eof channelId
```

### Example
```tcl
set fileId [open "report.txt" "r"]
while {![eof $fileId]} {
    if {[gets $fileId line] >= 0} {
        puts "Read: $line"
    }
}
close $fileId
```

## Buffer and Position Management

### Explanation
I/O is typically buffered. You can force a write to disk using `flush`. You can also query or change the current read/write position using `tell` and `seek`.

### Syntax
```tcl
flush channelId
seek channelId offset ?origin?
tell channelId
```

## File System Operations

### Explanation
The `file` command provides numerous subcommands to query file metadata, check existence, and manipulate paths.

### Syntax
```tcl
file exists filename
file size filename
file mtime filename
file dirname filename
file tail filename
file join dir file
```

### Example
```tcl
set path "designs/module_a/top.v"
puts "Directory: [file dirname $path]"
puts "File: [file tail $path]"
```

## Globbing and Directories

### Explanation
`glob` finds files matching wildcard patterns. `pwd` gets the current working directory, and `cd` changes it.

### Syntax
```tcl
glob ?-nocomplain? ?-directory dir? ?-types type? pattern
pwd
cd dirName
```
