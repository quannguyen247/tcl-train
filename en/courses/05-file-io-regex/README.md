# Module 05: File I/O and Regex

This module focuses on reading and writing files with `open`, `gets`, `puts`, and `close`, then extracting data with `regexp`.

---

## 📖 Core Theory

### 1. File I/O
Tcl can open files to write logs, read reports, or export analysis results. This is essential when working with timing reports or ATPG logs.

### 2. Regular Expressions
`regexp` is used to search and capture values from text, such as `Slack`, `Arrival`, or pattern counts from a report.
