# Regex practice

Run an example from this directory with `tclsh regex_lab1.tcl`, or run all examples through `python3 eda/dft/run_labs.py` at the repository root.

The ten scripts practice identifiers, Verilog-style hexadecimal values, instance naming, signed decimals, bus ranges, SDC substitutions, dates, line comments, MAC addresses, and masking a slack value. Change an input and predict whether it matches before running the script. These patterns cover the listed examples only; they do not implement the complete Verilog or SDC grammar.
