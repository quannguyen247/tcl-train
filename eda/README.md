# EDA learning tracks

- [DFT and ASIC](dft/README.md): Tcl exercises, scan, fault simulation, and an RTL-to-GDS capstone.
- [Yosys](yosys/README.md): a standalone synthesis template.
- [Vivado](vivado/README.md): Tcl examples for FPGA projects.

The tracks use different tools and design targets. A synthetic report in a lesson is not a measurement from a physical design.
