# Các Lệnh Tcl Vivado Thông Dụng (Common)

Thư mục này chứa các lệnh Vivado Tcl cơ bản và cần thiết nhất cho quy trình quản lý dự án (project flow), tổng hợp (synthesis), thực thi (implementation), cấu hình ràng buộc (constraints) và phân tích cơ bản.

## Các chủ đề

1. Quản lý dự án
2. Tổng hợp & Thực thi
3. Ràng buộc thời gian (Timing Constraints)
4. Ràng buộc vật lý (Physical Constraints)
5. Báo cáo và Phân tích
6. Quản lý IP
7. Cơ bản về Mô phỏng (Simulation)
8. Truy vấn Netlist cơ bản
