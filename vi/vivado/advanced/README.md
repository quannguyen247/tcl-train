# Các Lệnh Tcl Vivado Nâng Cao (Advanced)

Thư mục này bao gồm các lệnh thao tác trực tiếp lên netlist, tự động hóa IP Integrator (Block Design), Kiểm tra luật thiết kế tùy chỉnh (Custom DRC), phân tích thời gian nâng cao và gỡ lỗi phần cứng (Hardware Debug).

## Các chủ đề

1. Truy vấn Netlist nâng cao
2. Thao tác và biến đổi Netlist
3. Checkpoint cho quy trình Batch Flow
4. Tự động hóa IP Integrator (BD)
5. Custom DRC và Hooks
6. Phân tích Timing nâng cao & CDC
7. Partial Reconfiguration (DFX)
8. Gỡ lỗi qua Hardware Manager
