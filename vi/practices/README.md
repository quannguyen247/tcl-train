# Bài tập Thực hành Exercism Tcl Track

Toàn bộ các bài tập thực hành trong thư mục này được trích xuất và tham khảo từ trang web học lập trình mã nguồn mở [Exercism Tcl Track](https://exercism.org/tracks/tcl).

## Cấu trúc Bài tập
Mỗi thư mục bài tập bao gồm:
- `<tên_bài>.tcl`: Chứa Đề bài nằm dưới dạng Comment (`# ...`) ở đầu file, nối tiếp bởi Sườn code giải bài.
- `<tên_bài>.test.tcl`: Bộ test case chuẩn viết bằng thư viện `tcltest`.

## Hướng dẫn Chấm Test
Để chấm tự động toàn bộ 140 bài tập, hãy mở terminal và chạy:
```bash
python run_all_tests.py
```
