# Module 05: File I/O và Regex

Module này tập trung vào đọc/ghi file bằng `open`, `gets`, `puts`, `close` và trích xuất dữ liệu bằng `regexp`.

---

## 📖 Kiến thức cốt lõi

### 1. File I/O
Tcl có thể mở file để ghi log, đọc report, hoặc xuất kết quả phân tích. Đây là kỹ năng rất quan trọng khi làm việc với timing report hoặc ATPG log.

### 2. Regular Expression
`regexp` dùng để tìm và bắt giá trị từ chuỗi văn bản, ví dụ lấy ra `Slack`, `Arrival`, hoặc số pattern từ report.
