# Module 04: Cấu trúc dữ liệu (Data Structures)

Module này giới thiệu cách làm việc với `list`, `array` và `dict` trong Tcl.

---

## 📖 Kiến thức cốt lõi

### 1. `list`
`list` phù hợp khi cần lưu một dãy phần tử có thứ tự, ví dụ danh sách clock domain hoặc danh sách pin.

### 2. `array`
`array` là cấu trúc key-value dạng associative array, rất tiện để đếm số lượng cell theo loại hoặc lưu thuộc tính đơn giản.

### 3. `dict`
`dict` phù hợp cho dữ liệu có cấu trúc rõ ràng hơn, đặc biệt khi cần ánh xạ nhiều khóa vào giá trị liên quan tới timing report hoặc configuration.
