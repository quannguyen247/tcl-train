## Mở và Đóng file

### Giải thích
Để tương tác với một file, bạn phải mở nó bằng lệnh `open`, trả về một định danh kênh (channel ID). Sử dụng channel ID này cho các thao tác tiếp theo và dùng lệnh `close` khi hoàn tất để giải phóng tài nguyên.

### Cú pháp
```tcl
set channelId [open filename mode]
close $channelId
```
Các chế độ bao gồm `r` (đọc), `w` (ghi, xóa nội dung cũ), `a` (ghi tiếp), `r+` (đọc/ghi), `w+` (đọc/ghi, xóa nội dung cũ), `a+` (đọc/ghi, ghi tiếp).

### Ví dụ
```tcl
set fileId [open "report.txt" "w"]
puts $fileId "Generated by EDA Tool"
close $fileId
```

### Kết quả
```
(Một file tên report.txt được tạo ra với nội dung tương ứng)
```

## Đọc và Ghi

### Giải thích
Bạn có thể đọc file theo từng dòng với lệnh `gets`, hoặc đọc toàn bộ bằng lệnh `read`. Sử dụng lệnh `puts` để ghi dữ liệu.

### Cú pháp
```tcl
gets channelId varName
read channelId ?numBytes?
puts ?-nonewline? channelId string
eof channelId
```

### Ví dụ
```tcl
set fileId [open "report.txt" "r"]
while {![eof $fileId]} {
    if {[gets $fileId line] >= 0} {
        puts "Read: $line"
    }
}
close $fileId
```

## Quản lý Buffer và Vị trí

### Giải thích
Việc I/O thường được đệm (buffered). Bạn có thể ép ghi vào đĩa bằng lệnh `flush`. Cũng có thể truy vấn hoặc thay đổi vị trí hiện tại bằng lệnh `tell` và `seek`.

### Cú pháp
```tcl
flush channelId
seek channelId offset ?origin?
tell channelId
```

## Các thao tác Hệ thống Tập tin

### Giải thích
Lệnh `file` cung cấp nhiều lệnh con để lấy thông tin metadata, kiểm tra sự tồn tại và thao tác trên đường dẫn file.

### Cú pháp
```tcl
file exists filename
file size filename
file mtime filename
file dirname filename
file tail filename
file join dir file
```

### Ví dụ
```tcl
set path "designs/module_a/top.v"
puts "Directory: [file dirname $path]"
puts "File: [file tail $path]"
```

## Tìm kiếm file và Thư mục

### Giải thích
Lệnh `glob` tìm kiếm file khớp với các mẫu wildcard. Lệnh `pwd` lấy thư mục làm việc hiện tại, và `cd` thay đổi thư mục đó.

### Cú pháp
```tcl
glob ?-nocomplain? ?-directory dir? ?-types type? pattern
pwd
cd dirName
```
